# 1. 基本句型 (骨架与组件)

- 主+谓 (S+V)

- 主+谓+双宾 (S+V+O+O)
- 主+谓+宾+补 (S+V+O+C)
- 存在句 (There be)

## 主语构成

- 普通名词/代词
- 非谓语 (V-ing / To do)
- 主语从句 (What/That...)
- 形式主语 (It...)

## 宾语 / 表语 / 补语构成

- 普通名词/形容词

- 非谓语/Wh-+To do
- 宾/表语从句
- 形式宾语 (It...)

# 5. 修饰与高阶句法

## A. 情绪与语气 (情态动词)

- Can / Could (能力/许可)
- Will / Would (意愿/请求)
- Must (必须/肯定推测)
- Shall / Should (建议/义务)
- May / Might (推测/许可)
- Have to / Used to / Be able to
- Ought to (应当)
- Need / Dare (情态用法)
- 推测/遗憾 (Modal + have done)

## B. 装饰名词 (定语结构)

- 形容词前置修饰
- 介词短语后置 (in/on/at)
- 限制性定语从句 (who/which/that)
- V-ing / V-ed 分词短语修饰
- To do 不定式短语修饰
- 非限制性定语从句 (, which)
- 介词+关系词 (in which / with whom)

## C. 装饰背景 (状语类型)

- 时间状语 (Time)
- 地点状语 (Place)
- 方式状语 (Manner)
- 原因状语 (Because/Since)
- 频率状语 (Often/Never)
- 条件状语 (If/Unless)
- 目的状语 (In order that)
- 比较状语 (Than/As...as)
- 程度状语 (Extremely...)
- 让步状语 (Although/Even if)
- 结果状语 (So...that)
- 观点/评注状语 (Frankly...)

## D. 名词性从句与并列

- 表语从句 (That is why...)
- 同位语从句 (The news that...)
- 关联连词 (Not only...but also)

## E. 高阶与特殊句法

- If 条件虚拟语气 (If I were...)
- 命令建议虚拟 ((should) do)
- Wish / As if 虚拟语气
- 部分倒装 (Never have I...)
- 完全倒装 (Here comes...)
- 强调句型 (It is...that)
- 非谓语完成态/被动态 (Having done)
- 独立主格 (Absolute Structure)
- 省略句 (Ellipsis)
- 插入语 (Parenthetical)

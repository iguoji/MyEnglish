# 我的英语（MyEnglish）

一款通过听音、配对、拼写和选词加深单词记忆的个人英语学习应用。目前提供 Android 版本，词库和学习记录保存在手机本地，无需注册账号。

当前仓库版本：**2.4.2（构建号 61）**，以 [pubspec.yaml](my_english/pubspec.yaml) 为准。

前半部分介绍如何使用，后半部分说明代码结构、数据规则和维护方式。

## 普通用户使用说明

### 从哪里开始

1. 打开右上角菜单，添加单词，或导入新版完整备份。
2. 在首页点击听音辨义、词义连连、拼写巩固或看义选词，开始当天的复习。
3. 想自己选词时，向上滑动展开词库，勾选 5–100 个单词，再通过底部学习入口选择模块并开始自测。
4. 只想听单词时，切换到随身听；勾选后播放选中的词，没有勾选时播放当前搜索结果。

词库顶部手柄或系统返回操作可以收起词库。底部入口左侧切换学习方式，中间开始，右侧继续上次的进度；没有可继续的进度时，右侧按钮不可用。

### 管理词库

- 点击单词播放发音，并展开或收起含义。
- 向左滑动单词行，可以编辑或删除。
- 搜索按英文拼写查找，忽略大小写，支持输入部分拼写。
- 单词按难度分区，区内可以调整排序；支持勾选、全选和反选。
- 搜索、刷新和从学习页面返回后，已勾选的单词仍然保留。

编辑和删除影响以后新开始的练习。已经开始的答题练习保留开局时的单词与题目，避免做到一半突然换题；随身听则在播放前读取最新内容，并跳过已删除的单词。

### 五种学习方式

| 方式 | 怎么练 |
| --- | --- |
| 随身听 | 按清单播放，可搜索、跳词、暂停和显示含义；默认每词两遍、间隔两秒、循环播放。 |
| 听音辨义 | 先听发音选拼写，再逐条选含义；完成一个词后，可以再试一次或进入下一词。 |
| 词义连连 | 连接英文和中文，不限时，每轮最多五对；会把容易产生配对歧义的组合分到不同轮次。 |
| 拼写巩固 | 听发音、看含义，用26个字母键拼词；空格、撇号和连字符自动显示，整词填完后判断。 |
| 看义选词 | 看中文选英文，每题四个候选，其中一个或两个正确；正确单词更多时分成多题练习。 |

候选会显示对错反馈，换题前留有短暂间隔，避免连续点按误答下一题。听音辨义里，不同词性下的相同中文仍可能是不同小题，例如 `close` 的动词“接近”和副词“接近”。

词义连连中，如果 `big` 有“大、重要”，而 `large` 有“大”，不会把 `big→重要` 和 `large→大` 放在同一轮，避免用户连到同样正确的含义却被判错；因此某些轮次可能不足五对。

随身听的搜索只筛选显示，不改变播放顺序。暂停保留当前词、已经读完的遍数和剩余间隔；未读完的一遍会从头朗读。切到后台或锁屏会暂停，播放清单可以跨天继续。

### 每日复习、巩固和自测

每日默认复习50个词，首页四个模块共用当天的计划。计划约四成选较难的词，六成选较久没复习的词，同时准备明天的计划。

- 词库不足50个时，先使用现有单词；以后增加单词会继续补足。
- 修改每日数量会调整计划，已经开始的练习继续完成原来的题目。
- 设置为0时不创建新的每日复习，已经开始的练习仍可继续。
- 某个模块完成当天复习后，再进入会开始巩固，尽量从今天、明天的计划各取一半；不足时补足，同局不重复选入同一个单词。
- 自测只使用明确勾选的 5–100 个单词；重新点击开始会新开一局，点击继续才恢复已有作答进度。
- 首页复习和词库自测分别保存进度；自测刚打开就退出、尚未答题时，不提供继续入口。

普通退出保留答题进度。跨天再打开 App 时，昨天没答完的练习会按已经答过的部分自动结算，并直接回到首页；一条答案都没答过的单词不结算，难度保持不动。“再来一次”沿用当前练习的来源：自测沿用原选词，每日复习完成后进入巩固。

### 结算与首页数字

完成全部题目后进入结算页，可以逐词选择变难、变易或不变。调整保存成功后才更新显示，返回首页或再来一次时正式应用；保存失败会提示重试。

- 中途答错不影响整局完成，但会影响这个词的结果和难度建议。
- 一个词当前这一遍的全部题目都答对、且没有答错记录，才算本局正确。
- 听音辨义的“再试一次”让整个单词重新开始，最终结算只看最后一遍。
- 答错建议难度加1；连续答对达到“连对变易”的设置值后，每次继续答对都建议减1，最低为0。
- 每日复习更新最近复习时间；巩固和自测只调整难度，随身听不产生答题结算。

首页的“今日复习”、单词数量曲线和打卡日历，都统计**已经确认结算的单词**：答错也算练过，同一天同一个词只计一次，数量可以超过每日目标。只练半局、还没有确认结算时，这些数字暂不增加。

应用被系统关闭后，下次启动会补交已经完成但尚未确认的结算。正常切到后台再回来，会保留仍在编辑的结算页。同一局不会重复调整难度。跨天再回到 App 时，昨天没答完的练习按已答过的小题默默结算（不弹结算页、不能手动调难度），停在答题页的用户会被送回首页。

### 设置、发音和备份

菜单可以调整主题、口音、含义分隔符、字号、每日复习数量和连对变易次数。默认使用浅色主题、美式发音；字号也会跟随手机系统设置。

发音会在可用来源中轮换，并在没有可用网络发音时尝试手机本地英语语音。可以提前下载离线音频；来源不可用时会提示播放问题。

完整备份包含词库、设置、每日计划、题目、答案、结算和继续学习所需的状态，不包含下载的音频和运行日志。

**导入完整备份会替换当前数据，导入前请先导出一份备份。** 文件格式或关联错误时，整次导入撤回，保留原数据。如果提示“备份已导入，但界面刷新失败”，说明数据已替换，应重新打开应用。

新版首次使用的是独立数据库，原来的数据库文件保留，但不会自动迁入旧词库和旧练习记录。旧版备份需要先转换；转换只搬运词库和适用设置，不搬运旧计划与练习历史。卸载应用会删除本地数据，备份文件应保存在应用之外。

### 运行环境与目录

应用使用 Flutter/Dart，Android 端使用 Kotlin 和 SQLite。仓库当前只包含 Android 工程，Dart SDK 要求以 `pubspec.yaml` 为准。界面使用统一的 Tabler 风格和图标。


现行需求依据为 [功能描述](memory/功能描述.md) 和 [数据结构](memory/数据结构.md)，以及后续明确确认的补充规则。两份文档可能仍有未覆盖的边界；旧注释和历史工具不能作为新规则的依据。

所有学习页面使用 `ModuleScaffold`；只有四种答题模块使用 `SessionProgress`。随身听直接保存编号清单，不创建新的会话或复制整份单词正文。

首页卡片和词库入口共用防重复打开的控制，覆盖开局、页面停留和“再来一次”。数据库操作使用同一个串行队列；应用退出时，数据库关闭排在已接收的写入之后。

### 数据结构与时间口径

数据库文件为 `my_english_v3.db`，数据库结构版本为1；完整备份格式版本为3；应用版本来自 `pubspec.yaml`。这三个版本分别管理不同内容，不要求相同。旧 `my_english_v2.db` 文件保留。

| 表 | 保存内容 |
| --- | --- |
| `settings` | 偏好、会话内容副本、混淆补充和独立播放清单。 |
| `words` | 拼写、难度、混淆词、保留的音节字段和最近复习时间。 |
| `word_meanings` | 原始含义、主词性、子词性及排序。 |
| `plans` | 按日期唯一的有效计划。 |
| `plan_words` | 计划中的单词及难词／久词身份。 |
| `sessions` | 模块、日期、类型、状态、结算状态和用时。 |
| `session_main_questions` | 大题顺序、阶段、重试次数及当前小题。 |
| `session_sub_questions` | 题型、内容、答案、候选及实际用时。 |
| `session_question_details` | 小题对应的原始单词和含义编号。 |
| `session_question_answers` | 小题、尝试序号、文本答案和对错。 |
| `session_word_settlements` | 每局每词的结算草稿、落实状态及难度变化。 |

全部表包含 `id`、`created_at`、`updated_at`、`deleted_at`。创建、修改、删除和复习时间使用整数毫秒；计划、会话和结算归属日期使用 `YYYY-MM-DD`；累计及实际用时使用秒。

普通删除使用软删除，也就是保留记录并标记删除。普通查询排除这些记录，完整备份保留它们，以维持历史关联。整库导入和清空数据属于维护操作，允许物理替换。

会话类型为1复习、2巩固、3自测；状态为0失败、1完成、2进行中、3中断；结算状态为0未结算、1已结算、2无需结算。

会话开局内容保存在 `session.<编号>.snapshot` 设置中。后续生成的混淆字段以对应编号的补充项保存，恢复时合并。`Session.items`、`cursor` 和 `WordSet` 是供页面使用的查询结果，不能恢复成旧版独立 JSON 存储。

随身听使用唯一的 `listeningPlayback` 设置，保存清单编号、单词编号顺序及播放进度。旧 `session.<编号>.playback` 仍用于迁移和历史备份；新页面不能向旧链路写入。

完整 SQL 参考见 [schema_v3.sql](my_english/tools/schema_v3.sql)，实际建表以 `StudySchema.kt` 为准。

### 必须保持一致的业务规则

**计划选词：** 难词配额向上取整为总数的40%，其余为久词。同层内按下表逐项排序，前一项相同时再比较后一项。

| 层 | 排序优先级 |
| --- | --- |
| 难词 | 难度降序、含义数降序、含义字数降序、复习时间降序、拼写升序、编号升序。 |
| 久词 | 复习时间升序（空值优先）、含义数升序、含义字数升序、难度升序、拼写升序、编号升序。 |

计划获取时剔除已删除词、补缺或缩减；缩减保留两层配额。已开局试卷不随计划或每日目标变化。巩固先从两天各取一半，再补剩余明日词和今日词。

**题目身份：** 答案按文本判断，进度、题目和结算按编号关联。相同拼写的两条单词记录不能在结算时互相代替。英文比较忽略大小写，中文按去掉首尾空白后的文本精确比较。

**含义合并：** 听音辨义只合并动词范围内的相同释义，跨词性的同文含义仍是独立小题；它的槽位顺序必须与 `Word.verbMergedMeanings` 一致，明细只关联本题的具体含义记录。词义连连和看义选词按同词同中文合并，同时保留相关原始编号。不得把三个模块改成同一套无条件去重。

**连线：** 同轮中文不重复，相同拼写的卡片可互换；不同拼写之间，如果一方也具有另一张卡的含义，则在编排完成后拆轮，保持原配对完整。新编排只影响新会话，恢复时沿用已保存的试卷。

**选择题：** 每题四个不同文本候选，看义选词最多两个正确答案；更多同义单词分题。候选由混淆字段生成并保存，恢复后复用同一份内容，英文按字母、中文按固定字符顺序排列。

**重试与结算：** `attempt_no = retry_count + 1`，听音辨义重试整个单词时，其下所有小题共同进入新遍次，旧答案保留。单词当前遍次的全部题目完成且没有错误，才算本局正确。

**跨天收尾：** 启动或跨天回到前台时，`date` 不是今天的进行中会话统一收尾：答过至少一道小题的按「已答小题」结算（只要求已答部分全部正确，未答完的词也算数），一条答案都没答过的直接中断且不改难度。收尾与正常完成共用落实逻辑，结算归属日期仍是会话自身的日期。

会话完成、读取全部结算草稿成功后，才显示结算页；手动调整保存成功后才更新显示，保存中禁止最终提交。结算提交必须区分“已经提交”和“尚未完成而不能提交”，后者报错。后台恢复不能自动落实仍在编辑的结算页，启动和新开每日练习时可恢复遗留结算。

**统计：** 单词数量来自已经落实的结算，同日同词只计一次，答错也计入。复习、巩固、自测都参与，归属日期取会话日期。单词数量与页面累计停留时长是不同统计，不可混用；实际答题时间在公共控制器中计时，后台不计入。

### 备份与兼容范围

完整备份包含 `version: 3`、`time_unit: "milliseconds"` 和全部十一张表的数组。导入保留编号；字段、引用、快照或播放状态错误时，事务整体撤回。历史会话必须带上对应的内容副本和有效关联，不能只复制会话行。

导入还会检查含义是否属于对应单词、当前题目是否属于对应会话、结算单词是否出现在试卷中，以及试卷需要的含义是否存在于开局副本。数组原顺序和重复音节保留，不按候选词规则统一去重。

`convert_backup_to_v3.py` 用于把旧 version=2 备份转换为新版，只迁移词库及适用设置；`migrate_v2.py` 和 `schema_v2.sql` 是历史格式工具，输出不能直接当作新版完整备份导入。

重置设置保留答题会话，但清空随身听清单；清空全部数据会删除新版业务数据和离线音频。当前修复不会改写旧试卷，也不会自动修复过去已经保存的失败状态或不一致题目。

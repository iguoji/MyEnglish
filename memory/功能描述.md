### 组件

#### 单词列表播放器

对当前计划中的单词进行播放，播放时将当前单词聚焦于列表正中间，单词可设置只显示首字母，每个单词可设置播放次数、间隔，同时还有以下功能：

搜索：输入关键字对单词列表进行筛选，不改变当前播放计划

到顶：滚动条.scrollTop = 0

到底：滚动条.scrollTop = 列表.height - 滚动条.height

切换：点击列表中任意单词，切换到该单词并开始播放

规则：

- 顺序：按照当前计划中的单词顺序进行播放
- 进入：默认选中第一个单词，并开始播放
- 播放：当前单词按照播放次数播放，播放完成后按照播放间隔继续播放或切换到下一个单词
- 当前：当前播放的单词保持选中，并聚焦在列表正中间
- 进度：当前单词在计划中的序号/计划单词总数，如1/50
- 列表循环：默认是，播放到最后一个后回到第一个继续播放
- 播放结束：列表循环关闭时，播放到最后一个后停止播放，并保持在最后一个单词

#### 列表播放控制器

对当前播放列表进行上一个、暂停、播放、下一个的操作

规则：
- 上一个：切换到上一个单词，并从第1次开始播放
- 暂停：暂停当前播放，保留当前单词、播放次数和播放位置
- 播放：从暂停位置继续播放
- 下一个：切换到下一个单词，并从第1次开始播放

#### 词义显示器

完整显示出当前单词、词性、含义，拥有显示与隐藏模式，可设置默认是显示还是隐藏，可设置是否支持按下显示

跟随：切换当前单词时同步切换单词、词性、含义

按下显示：开启后按住当前单词显示词义，松开后恢复隐藏

#### 扬声器

圆形容器，里面是扬声器图标

当单词音频处于播放状态时，将会产生三重变化

- 外层弧形线段动画
- 圆形容器背景变色
- 圆形容器波纹扩散

#### 答案槽位组

由多个答案槽位组成，每个槽位由下划线、闪烁光标、内容组成，根据其状态(已填充、当前项、待填充、禁用项)来做具体的显示

每个槽位的内容可以支持任意数量的字符，槽位的宽度根据内容宽度而来

通过HTML的方式举例：

```html
<!-- don't -->
<answer-slots mode="preview">
    <answer-slot active><label>d</label></answer-slot>
    <answer-slot><label>o</label></answer-slot>
    <answer-slot><label>n</label></answer-slot>
    <answer-slot disable><label>'</label></answer-slot>
    <answer-slot><label>t</label></answer-slot>
</answer-slots>
<!-- n. 招呼；问候 -->
<answer-slots mode="edit">
    <answer-slot active><label>招呼</label></answer-slot>
    <answer-slot disable><label>'</label></answer-slot>
    <answer-slot><label>问候</label></answer-slot>
</answer-slots>
```

其实说是槽位，实则不会进行任何后期填充，只是将已经内置好的字符显示出来而已

已填充：下划线隐藏、光标隐藏、内容显示

当前项：下划线高亮、光标闪烁、内容隐藏

待填充：下划线普通、光标隐藏、内容隐藏

禁用项：下划线隐藏、光标隐藏、内容显示，主要是为含义分隔符和单词连字符所准备

此组件支持编辑和预览模式，预览模式下所有槽位都将以"已填充"的形式展现

内容出现需要有出场动画，各个插槽内容之间的出场动画是独立的，但是是复用的同一套动画

当所有非禁用项都被填充时，可以支持整体标红或标绿的特效，即成功或失败，当然得看调用方是否启用和如何调用

成功：整体下划线和内容都标绿

失败：整体下划线和内容都标红且有颤动动画

#### 候选词组

由ABCD4个候选词组成，一行两个，从上至下从左至右排列

长得像按钮，错误则标红禁用，正确则标绿(单选题可能直接进入下一题了，所以看不到标绿效果)

#### 播音胶囊

圆角胶囊容器，宽高固定，布局分左右，左边是@扬声器组件，右边分上下，上面是条纹动画，下面是口音+播放状态提示文字

当单词音频处于播放状态时，将会产生三重变化

- 扬声器触发动画
- 条纹触发动画
- 口音状态文字变化

#### 含义及词性面板

整体由两部分组成，上面是固定的"词性及含义"+分割线，下面是多个词性含义组

每个词性含义组在一个圆角胶囊容器中，分左右布局，左边是词性徽章，右边是此词性的所有含义构成的@答案槽位组

此组件支持编辑和预览模式，对应@答案槽位组的编辑和预览模式


#### 词义连线组

整体由两部分组成，分左右两列显示

左边显示单词候选词，右边显示含义候选词，左右两边候选词数量始终保持一致

单词候选词右边框正中间有圆形锚点，含义候选词左边框正中间有圆形锚点

可在左右两边任选一个候选词开始，然后再到另一边选择一个候选词进行配对

错误则标红颤动，随后恢复正常状态

整个则标绿，并且自单词候选词的锚点开始延伸出一条绿色曲线来链接含义候选词的锚点

#### 26键键盘

整体处于灰色背景的容器中，分三排来显示26个字母和删除键

除删除键之外，所有键的宽高必须保持一致

删除键位于第三排的右边，宽度需略宽于其他按键

### 界面

#### 顶部

- 居上：使用类似paddingTop的方式填充顶部，使顶部保持安全距离

- 返回：返回按钮，仅显示里面的返回图标，图标居左对齐
- 进度：数字进度，如1/50，数字的语义由各个模块自行定义
- 时间：停留在当前界面的累计时间，格式mm:ss，超过一小时则hh:mm:ss

- 进度：使用进度条充当分割线

#### 正文

- 根据每个模块自定义显示对应的组件

#### 底部

- 居下：使用类似paddingBottom的方式填充底部，使底部保持安全距离
- 根据每个模块自定义显示对应的组件

#### 设置

默认没有设置，除非主动写明了才有

监听整体页面的向上滑动事件，将从底部滑出设置抽屉

#### 结算

> 所有可结算的复习模块使用统一的结算页面

正文：统计卡片、单词结算列表
底部：再来一次按钮、返回首页按钮

### 计划

> 计划按日期区分，每天的计划主要是用来维护今日模块复习的单词对象

```js
// 入口函数
function 获取计划(string 日期) {
    计划 = 数据库.查询计划(日期)

    if 非空(计划) {
        if (计划.存在单词表中已删除的单词()) {
            计划 = 计划.删除计划单词表数据(计划.编号)
        }
        if 计划.单词数量() != 全局设置.每日复习 {
            // 少了要补
            if 计划.单词数量() < 全局设置.每日复习 {
                [新增难词, 新增久词] = 优选单词(全局设置.每日复习 - 计划.单词数量(), 计划.单词列表())
                计划 = 计划.新增部分单词(新增难词, 新增久词)
            }
            // 多了要删
            if 计划.单词数量() > 全局设置.每日复习 {
                计划 = 计划.删除部分单词(计划.单词数量() - 全局设置.每日复习)
            }
        }
    } else {
        [今日难词, 今日久词] = 优选单词(全局设置.每日复习, [])
        计划 = 数据库.创建计划(日期, 今日难词, 今日久词)

        明天日期 = 明天(日期)
        明天计划 = 数据库.查询计划(明天日期)
        if 为空(明天计划) {
            [明天难词, 明天久词] = 优选单词(全局设置.每日复习, 计划.单词列表())
            数据库.创建计划(明天日期, 明天难词, 明天久词)
        }
    }

    return 计划
}

// 选词规则
// 复习时间升序时NULL值优先
function 优选单词(int 单词总数, array 过滤单词 = []) {
    难词数量 = ceil(单词总数 * 0.4)
    难词列表 = 全局词库.查询单词(
        count: 难词数量,
        sort: [按难度降序, 按含义数量降序, 按含义字数降序, 按复习时间降序, 按字母升序, 按编号升序],
        filter: 过滤单词
    )

    久词数量 = 单词总数 - 难词数量
    久词列表 = 全局词库.查询单词(
        count: 久词数量,
        sort: [按复习时间升序, 按含义数量升序, 按含义字数升序, 按难度升序, 按字母升序, 按编号升序],
        filter: [...难词列表, ...过滤单词]
    )
    return [难词列表, 久词列表]
}

```

### 会话

```js
// 入口函数
// 非首页模块必传类型=自测
function 获取会话(string 模块Key, string 类型 = null, array 单词列表 = null){
    if (类型 == 自测) {
        会话 = 数据库.查询会话(今天日期, 类型, 模块Key, 进行中)
        if (非空(会话) && 非空(单词列表)) 中断会话(会话.编号)
        if (为空(会话)) {
            if (为空(单词列表)) 单词列表 = 全局词库
            会话 = 新建会话(今天日期, 类型, 模块Key, 单词列表)
        }
    } else {
        会话 = 数据库.查询会话(今天日期, 复习||巩固, 模块Key, 进行中)

        // 只有为空才需要新建会话，计划调整、单词调整、每日复习调整都需要将现有会话完成再说
        if (为空(会话)) {
            类型 = 数据库.会话存在(今天日期, 复习, 模块Key, 已完成) ? 巩固 : 复习
            if 类型 == 复习 {
                计划 = 获取计划(今天日期);
                单词列表 = 计划.难词久词均匀混着排列返回()
            } else {
                计划 = 获取计划(今天日期);
                今天单词 = 计划.单词列表()

                明天计划 = 获取计划(明天日期);
                明天单词 = 明天计划.单词列表()

                单词列表 = 各取一半(今天单词, 明天单词).不足则优先明天单词().明天不足则取今天单词().总之要尽量凑齐每日复习数量().随机打乱()
            }
            会话 = 新建会话(今天日期, 类型, 模块Key, 单词列表, 计划.编号)
        }
    }

    return 会话
}

    })
}
```
